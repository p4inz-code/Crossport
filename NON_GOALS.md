# CrossPort Non-Goals

Version: 1.0

This document defines what CrossPort intentionally will not become.

These boundaries protect the project's identity and prevent feature creep.

---

# CrossPort Is NOT

- A disk partition manager
- A disk formatter
- A disk benchmark tool
- A disk recovery application
- A backup solution
- A cloud storage platform
- A cloud synchronization service
- A file explorer replacement
- An operating system optimizer
- A registry cleaner
- An antivirus
- A malware scanner
- A driver updater
- A system monitoring suite
- A virtualization platform

---

# CrossPort Will Not

- Require user accounts
- Require subscriptions
- Display advertisements
- Sell user data
- Collect telemetry by default
- Lock features behind paywalls
- Force updates
- Require internet for core functionality
- Include unnecessary background services

---

# Feature Acceptance Criteria

A feature should only be accepted if it directly improves:

- Cross-platform compatibility
- File movement
- Transfer reliability
- User safety
- Workflow efficiency

If a proposed feature does not strengthen one of these areas, it likely belongs in another product rather than CrossPort.

---

# Engineering Principle

Simple software is easier to trust.

CrossPort should remain focused, maintainable, and understandable throughout its lifetime.

---

# Final Principle

CrossPort aims to become the most recommended free tool for moving files between Windows, macOS, and Linux—not the largest desktop utility suite.

Every new feature should reinforce that mission.
