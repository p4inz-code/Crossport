# User Personas

## Persona 1 — The teacher (beginner)

Moves projects between a school Mac and a personal Windows PC. Wants the
shortest safe path with no configuration. Values clarity and confirmation
before any destructive action.

## Persona 2 — The creator (professional)

Shuttles large media/project folders between workstations. Needs speed,
progress feedback, pause/resume, and confidence that files arrived intact.

## Persona 3 — The power user (advanced)

Wants advanced mode: verification, retention policy, detailed logs, and
transfer preferences — without those controls cluttering the default
experience.

See `docs/product/USER_JOURNEYS.md` for journey-level flows.
